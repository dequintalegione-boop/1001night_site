# Управление сайтом через Google Таблицу

1. Загрузите `1001-noch-tablica.xlsx` в Google Диск → «Открыть в Google Таблицах». Названия вкладок (Сайт, Цены, Фото, Акции), ключи и первую строку не меняйте.
2. «Настройки доступа» → «Все, у кого есть ссылка» → «Читатель».
3. Скопируйте ID таблицы (в ссылке между `/d/` и `/edit`) и вставьте в `index.html` в строку `const SHEET_ID = '';`.
4. Обновите страницу. Изменения в таблице появляются на сайте сразу после обновления.

Вкладки: **Сайт** (телефоны, WhatsApp, адреса, часы, ссылки, рейтинг), **Цены** (список цен; пусто = остаются цены из кода), **Фото** (ссылка https://…, либо имя файла из корня проекта, например `interior.jpg`, либо путь `assets/photos/interior.jpg`; если файла нет в корне, сайт сам поищет его в `assets/photos/`), **Акции**: A — заголовок, B — пояснение (можно пусто), C — «да» или пусто показывает строку, «нет» скрывает. Первая строка таблицы — скрытый пример: замените её своей и поставьте «да». Если показываемых строк нет, блок на сайте не виден.
Если ID пустой или таблица недоступна, сайт работает с данными из кода.
