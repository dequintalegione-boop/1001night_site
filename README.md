# 1001 ночь — сайт кальянной в Тюмени (v2)

Одностраничный сайт на HTML, CSS и JavaScript. Без Node.js, сборки и сервера: откройте `index.html` в браузере (для шрифтов и фото нужен интернет). `index.html` самодостаточный: стили и скрипты внутри.

## Что есть
- Первый экран с дымкой, фото и карточками обоих филиалов (адрес, часы, телефон, карты, WhatsApp для «Центра»).
- Блок оценок гостей (Яндекс Карты: 4.9 и 5.0) со счётчиками.
- Блок «Цены и акции» (по Telegram-каналу и Яндекс Картам).
- Форма брони: «Центр» открывает WhatsApp с готовым текстом, «Европейский» показывает телефон.
- Галерея с лайтбоксом, анимации появления при прокрутке, мобильная панель «позвонить».
- SEO: описание, Open Graph, schema.org (LocalBusiness с координатами и рейтингом), пометка 18+.

## Фото
Все ссылки в блоке `SITE_IMAGES` внутри `index.html`. Сейчас это прямые ссылки на фото из открытых карточек на Яндекс Картах. Для постоянного размещения положите оригиналы в `assets/photos/` и укажите пути. См. `IMAGES_HOW_TO_CHANGE.md`.

## Проверить с владельцем перед публикацией
- Часы работы и акции (меняются, в Telegram есть дни с другим графиком).
- Права на фото.
- Своё доменное имя (тогда добавить `canonical`).
